Política de privacidad de UltiMusic

Última actualización: 22 de septiembre de 2026

UltiMusic es un reproductor de música local. La aplicación no recopila, almacena ni vende datos personales de sus usuarios.

Acceso a archivos

UltiMusic accede a las carpetas de música que el usuario selecciona en el dispositivo (mediante el Storage Access Framework de Android) para escanear y reproducir la biblioteca. Estos archivos no salen del dispositivo salvo que el propio usuario los comparta.

Servicios de terceros

Para obtener metadatos, carátulas y letras de canciones, la app realiza consultas a las siguientes APIs públicas, enviando únicamente términos de búsqueda (título, artista, álbum) necesarios para la consulta:

  • iTunes Search API (Apple)
  • Deezer API
  • Genius API
  • MusicBrainz
  • LRCLIB
  • YouTube Data API (Google) — usada para consultar estadísticas públicas de popularidad de artistas. Esta función usa YouTube API Services; al utilizarla, el usuario acepta también las Condiciones de servicio de YouTube y la Política de Privacidad de Google.

Ninguno de estos servicios recibe datos de identificación personal del usuario.

Publicidad y analítica

UltiMusic no muestra anuncios, no usa Firebase, Crashlytics ni ningún SDK de analítica o rastreo.

Cuentas

La app no requiere registro ni inicio de sesión.
